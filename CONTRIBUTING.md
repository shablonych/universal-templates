# Как добавить шаблон

Спасибо, что хочешь помочь. Любой вклад важен: от исправления опечатки до нового раздела.

## Быстрый способ (без Git)

1. Открой [Issues](../../issues) и создай задачу по шаблону «Новый шаблон».
2. Вставь текст шаблона. Мы сами добавим его в репозиторий.

## Через Pull Request

1. Сделай форк репозитория.
2. Добавь файл в подходящую папку `templates/<раздел>/` или `prompts/`.
3. Используй структуру ниже.
4. Добавь ссылку на файл в `README.md` раздела.
5. Открой Pull Request.

## Структура шаблона

```markdown
# Название шаблона

> Для чего: одно предложение.
> Кому подойдёт: перечисли роли или ситуации.

## Шаблон

[сам шаблон с полями в квадратных скобках]

## Советы

- 2–4 практических совета по заполнению.
```

## Правила

- Имена файлов: латиница, нижний регистр, через дефис (`meeting-notes.md`).
- Без рекламы, персональных данных и материалов под чужой лицензией.
- Один файл — один шаблон.
