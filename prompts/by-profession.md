# ИИ-промпты по профессиям

> Для чего: готовые промпты для типовых задач разных специалистов.

| Профессия | Промпт |
|---|---|
| Разработчик | `Проверь этот код на ошибки, уязвимости и читаемость. Предложи исправленную версию с комментариями. [код]` |
| Дизайнер | `Предложи 5 концепций [что] для [аудитория] в стиле [стиль]. Для каждой — идея, палитра, шрифты.` |
| Маркетолог | `Составь контент-план на месяц для [продукт] в [соцсеть]: дата, тема, формат, призыв к действию.` |
| Продажи | `Напиши холодное письмо для [должность] в [отрасль] о [продукт]. Не длиннее 100 слов, с одним вопросом в конце.` |
| Руководитель | `Помоги подготовить обратную связь сотруднику: [ситуация]. Используй модель «ситуация — поведение — влияние».` |
| HR | `Составь вакансию [должность]: задачи, требования, условия. Тон — дружелюбный, без канцелярита.` |
| Учитель | `Составь план урока по теме [тема] для [класс/возраст] на 45 минут с интерактивным заданием.` |
| Бухгалтер / финансист | `Объясни [налоговое правило/понятие] простыми словами с числовым примером. Укажи, что проверить у специалиста.` |
| Юрист | `Перечисли риски в этом пункте договора для [стороны] и предложи более безопасную формулировку. [текст]` |
| Врач / медсестра | `Составь памятку для пациента о [тема] простым языком, без терминов, на одну страницу.` |
| Студент | `Составь план изучения [тема] за [срок]: темы по дням, ресурсы и вопросы для самопроверки.` |
| Предприниматель | `Проанализируй идею [идея]: целевая аудитория, конкуренты, риски, как проверить спрос за 2 недели без бюджета.` |

Не нашёл свою профессию? [Предложи промпт](../CONTRIBUTING.md).
