# Универсальные ИИ-промпты

> Для чего: получать от ИИ полезные ответы в любой сфере.
> Кому подойдёт: всем, кто пользуется ChatGPT, Claude, Perplexity, Gemini и другими ассистентами.

## Формула хорошего промпта

**Роль + Задача + Контекст + Формат + Ограничения**

```
Ты — [роль, например опытный юрист]. Помоги мне [задача].
Контекст: [кто я, для кого результат, что уже есть].
Формат ответа: [список / таблица / письмо / 3 варианта].
Ограничения: [объём, стиль, чего избегать].
```

## Готовые промпты

### Объяснить сложное просто
```
Объясни [тема] так, будто я новичок. Используй простой пример из жизни, затем дай краткое резюме в 3 пунктах.
```

### Улучшить текст
```
Улучши этот текст: сделай его короче, понятнее и вежливее, сохрани смысл. Покажи итог и список изменений.
[текст]
```

### Разбить задачу на шаги
```
Мне нужно [цель] к [срок]. Разбей на конкретные шаги с оценкой времени и укажи, с чего начать сегодня.
```

### Найти слабые места
```
Вот мой [план / текст / идея]. Сыграй роль строгого критика: найди 5 главных слабых мест и предложи, как их исправить.
[материал]
```

### Подготовиться к разговору
```
У меня скоро разговор с [кем] о [теме]. Моя цель — [цель]. Предложи план разговора, возможные возражения и ответы на них.
```

### Сделать выжимку
```
Сделай краткую выжимку этого материала: главная мысль, 5 ключевых фактов, что из этого следует для меня как [роль].
[материал]
```

## Советы

- Давай контекст: чем больше ИИ знает о задаче, тем точнее ответ.
- Проси несколько вариантов и выбирай лучший.
- Проверяй факты, цифры и юридические детали.
