# Универсальные шаблоны

[English](README.en.md) · **Русский**

Открытая библиотека готовых шаблонов, чек-листов и ИИ-промптов, которые пригодятся в любой профессии: от разработчика и дизайнера до бухгалтера, учителя и предпринимателя.

Всё написано в Markdown. Шаблон можно скопировать, заполнить и сразу использовать в Notion, Obsidian, Google Docs, Word или обычном текстовом файле.

## Что внутри

| Раздел | Для чего | Примеры |
|---|---|---|
| [Работа](templates/work) | Повседневные рабочие задачи | Протокол встречи, недельный отчёт, бриф проекта, ретроспектива |
| [Карьера](templates/career) | Поиск работы и развитие | Резюме, сопроводительное письмо, подготовка к собеседованию |
| [Бизнес](templates/business) | Своё дело и фриланс | Бизнес-план на одну страницу, коммерческое предложение, счёт |
| [Общение](templates/communication) | Письма и сообщения | Деловые письма, просьба, отказ, напоминание об оплате |
| [Чек-листы](templates/checklists) | Чтобы ничего не забыть | Онбординг, запуск проекта, принятие решений, «5 почему» |
| [Личное](templates/personal) | Жизнь вне работы | Бюджет, цели на год, сборы в поездку |
| [ИИ-промпты](prompts) | Работа с ChatGPT, Claude, Perplexity и др. | Универсальные промпты и промпты по профессиям |

## Как пользоваться

1. Найди нужный шаблон в таблице выше.
2. Нажми на файл, затем на кнопку «Copy raw file» (или просто выдели текст).
3. Вставь в свой редактор и замени текст в `[квадратных скобках]` на свой.

## Принципы

- **Универсальность.** Шаблон должен подходить людям из разных сфер.
- **Краткость.** Только то, что реально используется.
- **Практичность.** Каждый шаблон проверен в работе.
- **Свобода.** Лицензия CC0: используй как хочешь, даже без указания авторства.
