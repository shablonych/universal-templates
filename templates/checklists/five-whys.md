# Метод «5 почему»

> Для чего: найти корневую причину проблемы, а не лечить симптомы.
> Кому подойдёт: инженерам, менеджерам, сервису, производству, личному анализу.

## Шаблон

```markdown
**Проблема:** [что случилось]

1. Почему? → [...]
2. Почему? → [...]
3. Почему? → [...]
4. Почему? → [...]
5. Почему? → [...]

**Корневая причина:** [...]
**Действие, чтобы не повторилось:** [...] — ответственный [кто], срок [когда]
```

## Советы

- Ищи причины в процессах, а не в людях.
- Иногда хватает трёх «почему», иногда нужно семь.
