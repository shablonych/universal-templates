# Подготовка к собеседованию

> Для чего: прийти на собеседование уверенно и подготовленно.
> Кому подойдёт: соискателям любых уровней.

## Шаблон

```markdown
# Собеседование: [компания], [должность]  Дата: [...]

## О компании
- Чем занимается: [...]
- Новости и продукты: [...]

## Мои истории (метод STAR)
| Вопрос | Ситуация | Задача | Действие | Результат |
|---|---|---|---|---|
| Сложный проект | | | | |
| Конфликт | | | | |
| Ошибка и вывод | | | | |

## Мои вопросы работодателю
- Как выглядит успех на этой позиции через 3 месяца?
- Какие главные сложности у команды сейчас?

## Логистика
- [ ] Ссылка/адрес
- [ ] Резюме под рукой
```

## Советы

- Подготовь 5–6 историй, они закрывают большинство вопросов.
- Всегда задавай свои вопросы в конце.
