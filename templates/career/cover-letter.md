# Сопроводительное письмо

> Для чего: объяснить, почему вы подходите именно на эту вакансию.
> Кому подойдёт: соискателям.

## Шаблон

```markdown
Здравствуйте, [имя]!

Меня зовут [имя], я [должность] с опытом [N лет] в [сфера]. Откликаюсь на вакансию [название], потому что [конкретная причина, связанная с компанией].

Что я могу принести команде:
- [достижение, связанное с требованием вакансии]
- [ещё одно]

Буду рад(а) обсудить, как могу помочь [компания] с [задача из вакансии].

С уважением,
[Имя], [телефон]
```

## Советы

- Не пересказывай резюме — свяжи свой опыт с требованиями вакансии.
- Не длиннее 150–200 слов.
