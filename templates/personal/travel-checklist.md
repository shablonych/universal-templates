# Сборы в поездку

> Для чего: ничего не забыть в командировке или отпуске.
> Кому подойдёт: всем.

## Шаблон

```markdown
## Документы
- [ ] Паспорт / виза
- [ ] Билеты и бронь (офлайн-копии)
- [ ] Страховка
- [ ] Банковские карты и немного наличных

## Техника
- [ ] Телефон, зарядки, пауэрбанк
- [ ] Переходник для розеток
- [ ] Ноутбук (для работы)

## Здоровье
- [ ] Личные лекарства
- [ ] Аптечка

## Перед выходом
- [ ] Выключить плиту, воду, свет
- [ ] Предупредить банк о поездке (если нужно)
```

## Советы

- Держи сфотографированные документы в облаке.
