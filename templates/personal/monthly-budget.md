# Бюджет на месяц

> Для чего: понять, куда уходят деньги, и начать откладывать.
> Кому подойдёт: всем.

## Шаблон

```markdown
# Бюджет: [месяц]

## Доходы
| Источник | План | Факт |
|---|---|---|

## Обязательные расходы
| Статья | План | Факт |
|---|---|---|
| Жильё | | |
| Еда | | |
| Транспорт | | |
| Связь и подписки | | |

## Переменные расходы
| Статья | План | Факт |
|---|---|---|

## Накопления (цель: 10–20% дохода)
[сумма]

## Итог: доходы − расходы = [...]
```

## Советы

- Откладывай в день получения дохода, а не в конце месяца.
- Проверь подписки: часто там скрыты лишние расходы.
